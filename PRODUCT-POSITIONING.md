# Product Positioning

## Product

**Product Pro Max Skills**

**Tagline:** From vibe to viable.

**Positioning:** An open-source, evidence-driven product system for AI-native builders.

## Primary user

Solo technical founders, indie hackers and AI-native developers who can ship software quickly with coding agents but need stronger product judgment, UX rigor, engineering verification and distribution discipline.

## Core problem

AI has reduced the cost of implementation faster than it has reduced the cost of being wrong.

Builders can now produce software before validating whether the problem matters, who experiences it, what should be built, whether generated software works in reality, how users will find it or whether anyone will pay.

## Product promise

Help AI-native builders make better decisions across the full product lifecycle and attach evidence to those decisions.

## Differentiation

Product Pro Max Skills is not an awesome list, prompt dump, coding-style ruleset, framework starter or an autonomous agent that always keeps building.

It is a composable system centered on:

**Skill → Artifact → Evidence → Gate → Decision**

## Initial wedge

Evidence-driven productization for AI-native builders: validate value, constrain scope, verify implementation and create a path to users.
