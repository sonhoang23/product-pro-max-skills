# distribution-plan

## Purpose

Replace vague “post on social media” advice with a testable path to target users.

## Trigger

Use when ICP and product promise are specific enough to identify where prospects already gather.

**Do not use when:** Do not choose channels because they are popular with founders rather than used by the target segment.

## Inputs

### Required

- ICP.
- Positioning/value proposition.
- Product stage.

### Optional

- Existing audience.
- Channel access.
- Budget.
- Geography.
- Content or sales capabilities.

## Workflow

1. Identify where the ICP already searches, works, learns or asks for help.
2. Rank channels by target density, access, trust and feedback speed.
3. Define the message for each chosen channel from the ICP's pain language.
4. Create one concrete distribution asset and CTA per initial experiment.
5. Define leading and outcome metrics.
6. Set a time-box or sample size before judging the channel.
7. Feed acquired conversations back into product evidence.

## Evidence rules

- Never invent customer, market, test, runtime or revenue evidence.
- Label material claims as provided, observed, researched, measured, inferred or assumed.
- Preserve contradictory evidence.
- If evidence is unavailable, mark it unknown and lower the gate instead of filling the gap with confidence.
- Keep machine-facing semantics stable; present user-facing prose in the user's requested language.

## Output contract

Return these semantic fields:

- Channel thesis
- Priority channels
- Message
- Distribution asset
- CTA
- Experiment
- Metrics
- Failure criteria
- Feedback loop
- Gate

Rendering may be Markdown, YAML or JSON if requested, but facts, assumptions, risks, gate and decision must remain distinguishable.

## Quality gate

PASS when at least one channel has a credible access path, specific message, CTA and measurement plan. WARN when access exists but message evidence is weak. FAIL when the plan is generic broadcasting with no ICP concentration.

## Stop conditions

- ICP is too broad to identify concentrated channels; narrow it first.
- The proposed tactic violates platform/community rules.

## Anti-patterns

- Post on X/Reddit/Product Hunt as a strategy.
- Measuring impressions instead of target-user actions.
- Using the same message in every channel.

## Example

For recruiting agencies, a targeted workflow teardown in recruiter communities may beat a generic launch post.
