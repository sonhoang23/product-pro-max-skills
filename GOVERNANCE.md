# Governance

The project starts with a lightweight maintainer model.

- Maintainers own repository direction and quality.
- Area reviewers may emerge for product, design, engineering, security, growth and localization.
- Contributors can propose skills, evals, examples, docs and tooling.

Maintainers prioritize, in order:

1. user value;
2. evidence quality;
3. verification strength;
4. composability;
5. simplicity;
6. ecosystem compatibility;
7. skill count last.

Formal governance should grow only when contribution volume requires it.
